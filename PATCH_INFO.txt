Saku Kasir V56 — Small-DPI UI scale adjustment

Baseline: V53-R1

Authentication changes:
- Removed role-selection screen before login.
- One login page for Owner and Cashier.
- Login UI uses Username + Password only.
- Owner registration order: Username, Email, Password, Confirm Password, Owner Name, Business, Outlet, WhatsApp.
- Owner remains backed by Firebase Authentication Email/Password; email is used internally for Auth/recovery.
- Cashier accounts are created by Owner with Username + Password and a secondary Firebase Auth instance, so creating a cashier does not sign out the Owner.
- Cashier and Owner profiles are stored in RTDB and role is resolved after authentication.
- Removed local PIN/hash credential storage from SecureLocalStore.
- Added loginIndex mapping for username -> Firebase Auth email/UID/role.
- Password reset is available for Owner accounts via their registered email; Cashier password reset is Owner-managed.
- Guest/Anonymous Auth architecture is not removed by this patch.

Important: Firebase Console Authentication must have Email/Password provider enabled.
Database rules must be deployed from database.rules.json for loginIndex and cashier profile writes.


UI-only change in this overwrite:
- Reduced Compose global design scale from 1.10x to 0.90x so the UI is smaller on small-DPI/small-screen devices.
- Authentication and database rules are unchanged.
