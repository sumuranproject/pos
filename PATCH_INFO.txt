V64 REGISTRATION FORM PATCH — based on V62

Registration UI:
- Owner registration is now split into 2 pages/steps.
- Step 1: Username, Email, Password.
- Step 2: Nama Bisnis, Tipe Bisnis, Nomor HP.
- Step 1 validates before advancing to Step 2.
- Back button/system Back returns from Step 2 to Step 1 before leaving registration.
- Removed old Owner Name, Confirm Password, Outlet Name, and optional WhatsApp fields from the registration UI.
- Existing login screen and V62 centered login layout are preserved.

Registration data:
- Firebase owner registration now accepts business type.
- Business record stores name, type, and phone.
- A default initial outlet is created using the business name so the existing POS flow still has an outlet.
- Owner displayName falls back to username because the old Owner Name field is no longer part of registration.

Preserved:
- V62 Auth/Firebase flow.
- V62 Firebase Rules.
- V62 UI/IME/status-bar/navigation handling.
- No diagnostic/log feature added.
